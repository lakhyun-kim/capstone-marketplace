# 정기 분석 리포트

입력은 대상과 기간입니다. 빠졌으면 사용자에게 먼저 묻습니다.

## 절차
1. my-kit:price-summarizer 에이전트에게 대상과 기간의 자료 수집과 집계를 맡깁니다. 요청에 다른 my-kit: 에이전트가 적혀 있으면 그 에이전트에게 맡깁니다.
2. 받은 결과를 아래 출력 형식 그대로 정리합니다. 형식의 항목 이름과 순서를 바꾸지 않습니다.
3. my-kit:anomaly-checker 에이전트에게 초안 검토를 맡겨 PASS, WARN, FAIL을 받습니다. FAIL이면 지적을 고친 뒤 한 번 더 검토받습니다.
4. reports/ 폴더에 두 파일로 저장합니다. "기간-대상.md"는 아래 출력 형식, "기간-대상.html"은 아래 웹 리포트 형식입니다. 같은 대상의 지난 리포트가 있으면 3번 항목에서 비교합니다.

## 출력 형식
# (대상) 정기 리포트 (기간)
1. 요약: 세 줄 이내
2. 핵심 표: 항목, 값, 직전 리포트 대비, 출처
3. 눈에 띄는 변화와 이유
4. 확인하지 못한 것
5. 검토 결과: PASS, WARN, FAIL 중 하나와 한 줄 이유

## 웹 리포트 형식 (HTML)
- 비개발자가 보는 한 장짜리 보고서입니다. 외부 라이브러리나 CDN 없이 HTML 파일 하나로 만들고, 차트는 인라인 SVG로 그립니다.
- 순서: 제목과 기간, 데이터 기준 / 세 줄 요약 박스 / KPI 카드 3~4개 / 막대 차트 1~2개 / 핵심 표(위 2번과 같은 항목) / 확인하지 못한 것 / 검토 결과
- 숫자는 md 리포트와 같은 값만 씁니다. 인쇄하거나 PDF로 저장해도 한 장에 들어가게 합니다.

## 지키는 것
- 이 plugin의 에이전트와 MCP 도구가 준 자료만 씁니다.
- 개인 식별 정보(이름, 주민번호, 카드, 계좌, 휴대폰, customer_id, 건물명과 번지)와 키, 토큰 값은 쓰지 않습니다.
